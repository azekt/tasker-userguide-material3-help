GD Trash

Put a file or folder from Google Drive into or out of Trash.

Note: For security reasons this action can't be used on App Factory generated apps.

Output Variables

Details about the trashed / untrashed file or folder

Action Inputs

Google Drive Account

The account you want to the files with

Type

  • File Id: Trash a file by its ID. You can get the Id after you upload the file, or with a GD List action (check the output variables).
  • Remote Path: Trash a file or folder by specifying its Google Drive path. If you only specify the Remote Folder field, a folder and its contents will be trashed. If you also specify the Remote File Name field, only a single file will be trashed.

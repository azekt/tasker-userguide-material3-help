Assistance Request

The user has just requested assistance within the specified app.

Related video

  • Tasker - Customizable Assistant

On standard Android devices, this occurs when the user holds the bottom middle button of the display.

Some ROMs do not support specification of an App.

When setting Tasker as your assistant make sure to enable the Menu / More / Android Settings / Assistance Settings / Use text from screen option so that Tasker can get the necessary info to correctly trigger this event.

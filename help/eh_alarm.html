Alarm Clock

The Android alarm clock with the specified label is about to go off.

Stop Event will prevent the system responding to the alarm in any way. It's unknown if this causes future problems.

If you have a 3rd Party alarm, it may have its own event in the 3rd Party event category. Not all alarm packages pass along the label of the alarm.

Please note that some alarm clock apps (or some versions) might not send the correct intent to make this condition trigger properly. In that case there's nothing Tasker can do to change that behaviour.

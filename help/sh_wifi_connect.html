Wifi Connected

The device is connected to a Wi-Fi Access Point (AP).

If any of the parameters are specified, the AP must match that parameter, otherwise any AP will match.

You can use the variable Wifi Info to see information about the current AP (when connected).

Action Inputs

SSID

The SSID of the AP e.g. SKY34312

MAC

The MAC address of the AP e.g. 00:1f:35:34:43:4a

IP

The IP address of the AP e.g. 192.156.98.4

Active

Specifies whether or not the Wi-Fi network must be the network currently in use in order to match. Setting it to Yes means the Wi-Fi must be the default route to the internet. If Yes and you enable VPN, the Wi-Fi state rightfully becomes inactive, as that Wi-Fi connection is only used to route traffic to the VPN. The VPN has default route to internet. Any means it doesn't matter if Wi-Fi is route to internet or not, as long as you are connected to a Wi-Fi

Calendar Insert

Insert an entry into the specified calendar.

In / For (Minutes): the number of minutes (integer, not decimal) from now at which the calendar entry should start. Optionally, For how many minutes the calendar entry should last.

The default for In / For (Minutes) is 0 / 0.

Available: if not clicked, the calendar entry is marked as 'Busy' (see Menu / Show Extra Options in the Calendar app).

Tip: if you want to use variables with In / For (Minutes), be sure to leave spaces otherwise the variables won't be recognized.

Variable Join

Join all the values in the array %ARR into a single simple variable with the given Joiner.

Example: if %VAR1 = I, %VAR2 = like and %VAR3 = humus then after the action:

Variable Join

Name%VAR

Joiner;

Delete Parts

there will be a single variable %VAR with the value I;like;humus.

Any missing indices in the array will be completely skipped.

Arrays Merge

Allows you to merge 2 or more arrays together with a given format.

A lot of times in Tasker you end up with multiple related arrays.

For example, if you have

  • array %names with the values João,John
  • array %lastnames with the values Dias,Days

you can merge them together with a simple white space joiner and end up with an array like João Dias,John Days or you could use the format %lastnames is %names's last name wich would result in another 2 item array with the values Dias is João's last name,Days is John's last name

Action Inputs

Names

One or more array names, each on its line.

Each of these arrays will need to have the same number of valuse.

Joiner

Will simply merge each position of the arrays above with the joiner.

For example, if you have 2 arrays %names and %ages and use the Joiner - it'll join %names(1) - $ages(1), %names(2) - $ages(2) and so on.

Output

Name of the array that will contain the formatted values.

Each position of this array will contain the corresponding positions of all the input arrays joined with the rules above.

Join Output

If set, will join the resulting array and make the output variable a single value instead of an array.

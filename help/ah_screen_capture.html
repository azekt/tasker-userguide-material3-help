Screen Capture

Record the screen on your phone.

You can also optionally add sound to your recording. The sound will be captured from your microphone.

Typical usage is:

  • Use Mode Startto begin recording in a task
  • Use Mode Stop to stop recording in a later task
  • If yo need to check the current status of the recording use the Mode Query

Action Inputs

Mode

You can either start, stop or query a screen capture.

Starting a capture when it's already started will result in an error.

Stopping a capture when it's already stopped will result in an error.

Use Query to know if a capture is currently ongoing or not (check the %sc_is_capturing variable).

Video Encoder

Will be H264 by default.

Resolution

Will use your screen's resolution by default.

Video Bitrate

The higher the bitrate, the less pixelated will the final video look.

Not all bitrates may be supported by all devices.

If not manually set, will be 5000000.

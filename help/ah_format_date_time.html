Parse/Format DateTime

Allows you to format a date and/or time in any format, from any kind of input date.

This action follows the principle of being very simple to use but, if you really want to, you can do some pretty crazy combinations of configurations. Easy to use, but powerful if you need it!

  • If you don't configure anything, the action will simply output a bunch of variables (day, month, year, etc) regarding the current date

  • You can specify an Output Format to, additionally, output another variable with the format you specify

    Check out all the output format options

  • You can specify multiple Output Formats if you want to simultaneously output into different formats. For example, you could want the date and time in different variables, and this allows you to do that easily
  • You can change the Formatted Variable Names so that you can for example specify 2 output formats and give them relevant names directly in this action.
  • If you change the Input Type from Now to something else, you can format/get variables regarding a date that's not the current one
  • You can use %TIMEMS (Milliseconds Since Epoch), %TIMES (Seconds since Epoch), ISO 8601 (a widely used format) or any other custom format you want with the Input Type Custom
  • If you use the Input Type Custom you can input one or multiple input dates each with its own Input Format if you want (you can use 1 input format for all of the inputs too if you want)
  • If you use multiple Inputs and multiple Output Formats at the same time, you'll get all the inputs formatted in all the outputs. For example, if you have 2 inputs and 3 output formats you'll end up with 6 output variables each with its own different input/format combination
  • On top of all of this you can enable the Get All Details option which will add a bunch of pre-determined variables to the output. Stuff like Minute of Day, Week of Year, Is Week Day and many more. Stuff that you may not always want but that can be handy sometimes!

Action Inputs

Input

One or more dates.

Can be direct values, values from variables or direct arrays (use %array, not %array().

Input Format

One or more date formats.

For example, yyyy/MM/dd HH:mm will correctly parse a date like 2021/03/05 14:18.

You can use a different format for each input.

If there are more inputs than formats, the last format on the list will be used for all the remainder of the inputs.

Input Separator

Separator will be comma or newline by default, depending if one of these characters is present in your text or not.

Set to a different separator manually if needed.

Output Format

One or more date formats.

For example, yyyy/MM/dd HH:mm will produce a date like 2021/03/05 14:18.

If you specify more than one output format, those formats will be applied to each input, so you'll have all the possible combinations of inputs and formats.

For example, if you have 2 inputs and 3 output formats, you'll get a total of 6 formatted values.

Check out all the possible formats below.

Output Offset Type

If you want you can add seconds, minutes, hours or days to the output. This offset type will be applied to all outputs.

Output Offset

The amount of offset for the type above.

Can be negative values.

You can use multiple offsets if you have more than one output.

Time Zone

The time zone for the input time.

Useful if you want to format date/time for timezones other than the current one.
